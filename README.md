# Ace Arms / AMYS ARMS three-tab website

Tabs: Ace Arms Dundee (purple), Ace Arms Newcastle (orange), AMYS ARMS Umzinto (navy/copper).

Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the repository root. Keep the logo and QR files inside `assets`.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

The QR points to https://saif99sk.github.io/amys-arms-landing/

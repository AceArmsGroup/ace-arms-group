# Ace Arms / AMYS ARMS three-tab website

Tabs: Ace Arms Dundee (purple), Ace Arms Newcastle (orange), AMYS ARMS Umzinto (blue/navy).

The QR code section has intentionally been removed from the website.

Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the repository root. Keep the two logo files inside `assets`.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
